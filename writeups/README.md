## 怎麼寫一篇好的 writeup

- **說清楚你怎麼想**,不只是貼指令 —— 面試官想看的是你的思路。
- 放**關鍵截圖**(打馬賽克遮住敏感資訊)。
- 最後寫一段**修補建議**:如果你是防守方,怎麼擋掉這個攻擊。
