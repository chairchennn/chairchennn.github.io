# FilmDoodle · 底片塗鴉機

👉 **線上使用：https://chairchennn.github.io/film/**

把手機或相機照片變成底片感的小工具，介面像在做手帳拼貼；手機和電腦都能用，也可以「加到主畫面」當 App 用。

- **一鍵塗鴉框**：多種風格（蠟筆塗鴉、奶油貼紙、花花世界、法式手繪、日式手繪、Y2K、顏文字、夢幻粉彩、螢光塗鴉），塗鴉只撒在照片邊緣、中間留給主角；可以調「圖案數量」（4–30 個）、大小、霓虹光暈，換排列（上下／四周／左右／四角／天空），按「換一組」重新排，也能「轉成貼圖」後個別移動或刪除
- **四格拍貼**：選 4 張照片排成直條或 2×2，12 種相紙（白、黑、粉、紫、薄荷、天空藍、彩虹光、格子、點點、星星、方格紙、底片），每格各自套底片色調，也可以每格分別調取景
- **文具工具列**（底部漂浮）：新增（換照片、上傳自己的貼圖）、印章（橡皮章墨水質感，印泥顏色可換）、裁切（比例、取景、旋轉）、紙膠帶（12 種，連續貼會換到別的邊角）、膠水（把貼圖黏好不會誤觸，長按可撕下單張）、便條（便條紙、方格紙片、迴紋針）；順序可以自己整理
- **復原／重做**：單張、四格各自記錄，連換照片都能復原（Ctrl / ⌘ + Z）
- **閃光燈底片感**：預設「閃光底片」——主體亮、背景快速變暗，加上顆粒、暗角、光暈與柔焦；另有 14 種底片風格色調
- **12 種相框**：35mm 齒孔底片（黑邊／橘色負片）、粗糙黑邊、120 中片幅、幻燈片框、拍立得、迷你／方形／寬幅相紙、白邊相紙、手帳紙（照片像印出來貼在點點／方格等紙上）
- **原創手繪貼圖**：蠟筆塗鴉系列用自製的「蠟筆筆刷」畫——沿線加手抖、帶粉筆顆粒，像直接畫在底片照片上；可上傳自己的 PNG
- **相機日期**：七段顯示器樣式的橘色日期（標準／小兩種大小），預設讀取照片的拍攝日期；塗鴉和貼圖會自動避開日期

## 隱私與安全設計

這個專案刻意做成「照片永遠不離開裝置」：

| 設計 | 做法 |
| --- | --- |
| 不上傳 | 沒有後端；所有運算都在瀏覽器的 `<canvas>` 裡完成 |
| 移除 EXIF / GPS | 匯出時重新繪製成新的 JPG，不會帶出原始照片的位置、相機型號等中繼資料 |
| 嚴格 CSP | `script-src 'self'`、不用 inline script / style、不載入任何第三方 JavaScript；只允許 Google Fonts 字型（字型請求會連到 Google，照片不會） |
| 最小儲存 | `localStorage` 只記住上次用的底片／邊框設定，不存照片 |
| 安全解析 | 讀拍攝日期的 EXIF 解析器只讀前 256KB、每個位移都有邊界檢查 |
| 離線 | Service worker 只快取程式本身，照片不經過它 |

## 技術

- 純 HTML / CSS / JavaScript（ES modules），沒有框架、沒有建置步驟
- 底片色調：每個預設是一組參數（白平衡、各色相偏移、曲線、分離色調…），烘焙成 33³ 的 3D LUT，再用四面體內插套到每個像素；拖曳滑桿時用 17³ 的 LUT 保持流暢
- 相框尺寸照實體規格：35mm 齒孔 2.8×1.98mm、間距 4.75mm；迷你相紙 54×86mm、畫面 46×62mm 等
- 閃光燈：在線性亮度空間依離中心的距離調整曝光（中心約 +0.5EV、角落約 −1.2EV），亮部柔和壓縮不死白
- 貼圖是 SVG path，用 `Path2D` 直接畫在 canvas 上，放多大都清楚
- 塗鴉框用「最佳候選」取樣（Mitchell's best-candidate）在邊緣權重區域平均撒點，大中小三種尺寸分層，同一組亂數種子在預覽和匯出時位置完全一樣；塗鴉畫在顆粒之前，看起來像印在底片上
- 匯出上限約 1500 萬像素，避免 iPhone Safari 的 canvas 記憶體限制

## 檔案

```
film/
├── index.html            介面
├── style.css             樣式（手機優先，寬螢幕變側欄）
├── js/app.js             介面、手勢（拖曳、雙指縮放旋轉）、匯出
├── js/film.js            底片色調引擎、顆粒／漏光／光暈、日期戳記
├── js/frames.js          相框
├── js/stickers.js        原創貼圖
├── js/doodles.js         塗鴉框產生器（風格包、排列、數量）
├── js/fourcut.js         四格拍貼（版面、相紙）
├── js/crayon.js          蠟筆筆刷（SVG path 打散成點、手抖、顆粒質感）與印章墨水筆刷
├── js/tape.js            紙膠帶（程式畫的花紋與撕邊）
├── js/art/               新風格貼圖（法式、日式、Y2K、蠟筆、印章、便條紙）與共用形狀工具
├── icons/tools/          文具工具列圖示（原創）
├── js/exif.js            讀取拍攝日期
├── sw.js                 離線快取
├── manifest.webmanifest  PWA 設定
└── TEAM.md               團隊角色、審查流程與決策紀錄
```

本機測試：在 repo 根目錄執行 `python3 -m http.server`，打開 http://localhost:8000/film/ 。

> 色調為一般底片風格的模擬，非任何廠商官方數值。貼圖與塗鴉圖案皆為原創繪製；顏文字為常見符號組合。

## 團隊與審查流程

每次改版由五個角色審查（網頁美感、侵權審查、貼圖美術、專案總監、品質與發布），流程與每次的決定記錄在 [TEAM.md](TEAM.md)。
